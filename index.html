          檢測明細 — 轉址鏈、掃描的 JS、原始回應標頭›
        
        

      


      

        本工具僅執行被動、非侵入的公開資源讀取：首頁、站內 JS 與其 source map、/.env 系列、/.git/config、security.txt 各一次 GET（勾選自動找頁時多讀 sitemap.xml / robots.txt），另向公開 DNS 查詢 SPF / DMARC 紀錄，不構成滲透測試。
        評分反映基礎防線的配置狀況，不代表網站沒有其他漏洞。
      

    


    
    

      

        

          
掃描之外 · 上線前五問

          
體檢儀只能回答第五題。前四題只有你自己，和讀得到程式碼的工具，答得出來。

        

        
    
          
  1. 01哪些東西被偷會出大事？
    金鑰、金流 HashKey、資料庫連線、使用者個資：只能存在後端與環境變數。
    2. 
          
  2. 02誰能碰哪些資料？
    每支 API 都在後端驗證身分與權限，前端送來的 user id、價格一律不信。
    3. 
          
  3. 03哪一段是你管不到的？
    第三方套件、金流、AI API：鎖版本、定期 audit、金鑰限制來源。
    4. 
          
  4. 04哪些規則絕對不能被打破？
    「一般會員永遠讀不到別人的訂單」這種句子，寫成測試，每次改完都跑。
    5. 
          
  5. 05外面有哪些門是開著的？
    HTTPS、安全標頭、Cookie、/.env、/.git、前端金鑰：這一題交給上面的體檢。
    6. 
          
  6. 讀得到程式碼的掃描：OpenAI Codex Security（在 Codex 輸入 /plugins 安裝，再說一句「Run a Codex Security scan on this repository.」）或 Claude Code 的 /security-review。只在自己的專案上跑。
    7.

關於

        
給用 Cursor、v0、Bolt、Lovable 搭站、但沒有資安背景的開發者與學生的免費工具。只讀取網站公開回傳的 HTTP 標頭與靜態檔案，每次體檢最多約 15 個一般瀏覽器也會送的 GET 請求，沒有注入、爆破、目錄列舉或 port 掃描。

        
世新大學學生的個人專案，程式碼、檢查規則與計分方式都公開在 GitHub。

      

      

        
隱私

        
報告只存在你的瀏覽器裡，分享連結的內容全部在網址中，伺服器不儲存任何報告或目標網址。使用量統計只有彙總數字；修復 Prompt 旁的 👍👎 只累計項目 ID 的正負計數。

        
為了處理濫用申訴，伺服器 log 會記錄「來源 IP 與被檢測的網域」，保留 7 天後自動刪除。訪客統計用 Cloudflare Web Analytics，不用 cookie、不追蹤個人。

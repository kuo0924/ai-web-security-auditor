# 參考截圖（不會放進 App）

這裡放原版 App 的截圖，只用來比對版面，**絕不放進 clone、也不放進商店素材**。

目前是空的：App Store 截圖在 `is1-ssl.mzstatic.com`，被這個 session 的網路政策擋掉了。

補截圖的方法：
1. 自己在 iPhone 上裝原版，走一遍免費流程截圖（不要付費、不要繞過付費牆），
   檔名用畫面 ID，例如 `S06-swipe.png`、`S09-archive-filled.png`。
2. 或在環境的網路設定允許 `is1-ssl.mzstatic.com`，讓 Claude 讀取商店截圖（共 9 張）。
